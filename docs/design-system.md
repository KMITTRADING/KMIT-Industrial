# Design system

Built in Phase 2. The living reference is `/[locale]/styleguide`, which renders
every token and every component in every state, in both directions. This file
is the written contract: what each component is for, what it accepts, and what
it must never be used for.

Read `docs/brand-tokens.md` for the palette derivation and the contrast matrix,
and `docs/decisions.md` for why the system looks the way it does.

---

## 1. The direction the system commits to

**Technical editorial.** Closer to a materials-science journal or a
precision-instrument manufacturer than to a software landing page.

What that means concretely:

| Decision  | Value                                             | Why                                                         |
| --------- | ------------------------------------------------- | ----------------------------------------------------------- |
| Geometry  | Near-square, radius 2 to 6px                      | A minerals processor, not a fintech app                     |
| Hierarchy | Hairline rules and background steps               | One shadow exists, and it belongs to overlays               |
| Colour    | One accent family, neutrals tinted toward it      | A second chromatic colour would need a different brand      |
| Type      | One family, Alexandria, across both scripts       | Weight and scale carry contrast; two families would compete |
| Data      | Tabular figures, forced LTR, real tables          | The specification is the content, not an illustration of it |
| Motion    | Under 300ms, ease-out expo, travel capped at 12px | Motion explains state changes; it is not decoration         |

### The three motifs

1. **The hairline.** Rules between rows, under headers, between sections. This is
   the system's structural device.
2. **The eyebrow.** A micro-label on a hairline above a section title. Uppercase
   in Latin, letter-spaced in Arabic. **Rationed to one per three sections.**
3. **The instrument enclosure.** An outer tray at radius 6 holding an inner plate
   at radius 3, concentric. Used by the grade matrix and nothing else.

### What is banned

Beyond CLAUDE.md §6: no gradient text, no glassmorphism, no coloured side-stripe
borders, no decorative status dots, no numbered section markers, no
three-identical-cards feature row, no em dash or en dash anywhere a reader can
see one (`npm run check:copy` enforces the last one).

## 2. Tokens

Generated by `scripts/build-tokens.mjs` into `src/styles/tokens.css`. Never hand
edited. Components reference semantic tokens (`--color-ink-secondary`), not ramp
stops (`--color-neutral-700`).

| Group        | Tokens                                                                                            | Notes                                                              |
| ------------ | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Accent ramp  | `--color-accent-50` to `-900`                                                                     | Ten stops, OKLCH, constant hue                                     |
| Neutral ramp | `--color-neutral-0` to `-950`                                                                     | Twelve stops, tinted toward the accent hue                         |
| Semantic     | `success` `warning` `danger` `info`, each with `-surface` and `-border`                           | Capped at the accent's chroma budget                               |
| Surfaces     | `page` `raised` `sunken` `accent-tint` `accent` `accent-deep` `inverse`                           | Light surfaces take standard inks, dark surfaces take inverse inks |
| Inks         | `primary` `secondary` `muted` `accent` `inverse` `inverse-secondary` `inverse-accent`             |                                                                    |
| Borders      | `subtle` `default` `strong` `inverse`, plus `--border-hairline/rule/emphasis`                     |                                                                    |
| Type         | `--text-2xs` to `--text-5xl`, fluid                                                               | Body on a 1.25 ratio, display on 1.414                             |
| Spacing      | `--spacing-section-sm/section/section-lg`                                                         | Coarse; industrial layouts need air                                |
| Radius       | `--radius-xs` 2px to `--radius-lg` 6px                                                            |                                                                    |
| Motion       | `--duration-press` 120ms to `--duration-reveal` 300ms, `--duration-exit` 140ms, `--ease-out-expo` | Exit is about two thirds of enter                                  |
| Z-index      | `--z-base` through `--z-skip-link`, eight named layers                                            | Never an arbitrary number                                          |

### Locale-aware typography

Keyed off `[dir]`, not `[lang]`, so a subtree that opts into the other direction
inherits the right rhythm. Arabic gets more leading (1.77 against 1.65), much
less negative tracking (`-0.004em` against `-0.018em`, because Arabic letterforms
connect and tightening them damages the joins), and a shorter measure (58ch
against 68ch, because Arabic sets wider per character).

## 3. Primitives

### Button

**Purpose.** Every action on the site.

**Variants.** `primary` (accent fill, one per view), `secondary` (bordered),
`ghost` (no chrome until hover), `link` (inline in prose, no padding),
`danger` (destructive only).
**Sizes.** `sm` `md` `lg`. **Props.** `iconStart`, `iconEnd`, `loading`,
`loadingLabel`, `block`.
**States.** hover, active (scales to 0.985 over 120ms), disabled, loading.

**A11y.** Minimum 44px tall. `aria-busy` while loading, with an
`sr-only` status. An icon-only button must be given an `aria-label`.

**Do.** Verb plus object: "Request a quote", not "Submit".
**Don't.** Two buttons with the same intent in one view. One label per intent,
used everywhere. Don't let a label wrap at desktop.

### Badge

**Purpose.** A short identifier or state marker.

**Variants.** `grade` and `certification` (forced LTR, tabular figures, because
`GCC-1250` and `ISO 9001` are identifiers that must not reorder inside Arabic
text), `neutral`, `info`, `success`, `warning`, `danger`.
**Sizes.** `sm` `md`.

**Do.** Pair a state colour with a word.
**Don't.** Put a decorative coloured dot in front of it.

### Card

**Purpose.** A separable object the reader can act on.

**Variants.** `plain`, `raised`, `sunken`, `accent`, `instrument`.
**Sub-components.** `CardPlate` (the inner plate of an instrument tray),
`CardHeader`, `CardBody`, `CardFooter`.

**Do.** Reach for a hairline, a background step or plain space first. A card is
for when a block is genuinely a separate object.
**Don't.** Nest cards. The one two-layer construction in the system is
`instrument`, it is used by the grade matrix, and nothing nests inside it.

### Table

**Purpose.** Specification data. On this site that is the content, not an
illustration of it.

**Sub-components.** `TableScroll` (labelled, focusable, keyboard-pannable scroll
region with a hint that disappears once panned), `Table`, `TableCaption`,
`TableHead` (`sticky` optional), `TableBody`, `TableRow`, `TableHeaderCell`
(optionally a sort control), `TableCell`, `TableRowHeader`.

**A11y.** A real `<caption>`. `scope` on every header. `aria-sort` on sortable
columns with an `sr-only` description of the current state. The scroll container
only enters the tab order when it actually scrolls.

**Do.** Mark every measurement `numeric`: it forces LTR and tabular figures.
**Don't.** Put a border above _and_ below every row. One hairline between rows,
one 2px rule under the header.

### Field

**Purpose.** Every form control, with its label, hint and error.

**Controls.** `TextInput`, `TextArea`, `Select`, `FileInput`.
**Props.** `label`, `hint`, `error`, `required`, `requiredLabel`, `optionalLabel`.

**A11y.** Label above the control, always visible. Hint and error wired through
`aria-describedby`. Error carries `role="alert"` and an icon, so state never
depends on colour. Required is marked in words as well as with an asterisk.
Controls are at least 44px tall.

**Don't.** Use a placeholder as a label. Ever.

### Tabs

**Purpose.** Alternate views of comparable content.

**A11y.** Full WAI-ARIA tabs pattern with roving focus: one tab stop for the
list, arrow keys to move within it. **Arrow keys are direction-aware** and
resolve "forward" from the computed direction, so ArrowLeft advances in Arabic.
Active tab is marked by a 3px rule and a weight change, not by colour alone.

### Accordion

**Purpose.** FAQ and progressive disclosure.

Built on native `<details>`/`<summary>`, so answers exist for a crawler whether
or not the panel is open, and the browser's in-page search can find them.
Multiple panels open by default; pass `single` to close the others.

**Don't.** Animate the panel height. It reflows every frame and buys a flourish.

### Dialog

Native `<dialog>` with `showModal()`, which gives the top layer, the focus trap,
inert background and Escape for free. Backdrop click dismisses only when the
pointer went down on the backdrop. Body scroll locks while open. One of the two
components allowed the system's single shadow.

### Tooltip

Supplementary only, never the sole home of a fact. Opens on hover **and** focus,
closes on Escape and blur. A short open delay is skipped if another tooltip
closed within 400ms, so scanning a row of abbreviations does not mean waiting
each time.

**Don't.** Put an interactive element inside one. That is a popover.

### Breadcrumbs

Separator is a CSS pseudo-element, so it flips with direction and is not read
aloud. Last item is the current page: unlinked, `aria-current="page"`.

### Pagination

Direction-aware arrows, page status in an `aria-live` region.

### Alert

**Tones.** `info` `success` `warning` `danger`. Each pairs a distinct icon with a
visible severity word, so the message survives greyscale and colour blindness.
`danger` uses `role="alert"`; the rest are polite status regions.

**Don't.** Use a thick coloured side border. Hairline like everything else.

### Skeleton

`Skeleton`, `SkeletonText`, `TableSkeleton`. Shaped like the content arriving,
never a spinner. The container announces once; the child bars stay silent.

### SectionHeader

`eyebrow` (optional and rationed), `title`, `lede`. `as` sets the semantic level,
`size` sets the visual one, and they are independent.

**Don't.** Float the lede into the opposite corner as a small paragraph. Stack it
under the title at a readable measure.

### StatBlock

Instrument readings, not a hero-metric row. Values are forced LTR and tabular,
and each can carry a `source`, which on this site is the test method. A number
without its method is the kind of claim this site exists to avoid.

### IconSet

Twenty-three glyphs drawn for this domain: mesh screen, jet mill, classifier,
silo, valve bag, jumbo bag, tanker, lab flask, extruder, particle size, plus
utility icons. 24px box, 1.5 stroke, round caps, `currentColor`, no fills.

Decorative by default (`aria-hidden`); pass `title` to give one an accessible
name. Nothing is direction-specific: an arrow that must point "forward" is
flipped by the consumer with `rtl:-scale-x-100`.

**Why not a library.** No general set ships a jumbo bag or an air classifier, and
substituting a generic box would be worse than drawing one. See ADR-017.

## 5. Layout

### SiteHeader

Sticky. Condenses once scrolled past, driven by an **IntersectionObserver on a
one-pixel sentinel**, which fires twice in a session rather than on every scroll
frame.

The Products entry opens a mega-menu exposing the grade matrix directly: code,
mesh, D50, coating, one row per grade, each a link. Escape closes, click-outside
closes, focus-out closes, and any navigation closes it.

`navItems` is a prop. The live site passes only routes that exist; the styleguide
passes the full Phase 3 set so the mega-menu can be reviewed before those routes
are built.

### SiteFooter

Technical sitemap in four columns: brand and location, routes, grades, standards.
Standards are a **list**, not a dot-joined string. The data-provenance line is
last, stating once for the whole site that every published value is typical and
carries a test method.

### LocaleSwitcher

Switches locale while staying on the same document, using the unprefixed pathname
from the i18n navigation wrapper. Each language is named in its own script.

### SkipLink

First focusable element on every page, rendered once by the locale layout.
Targets `#main`, which every page must provide.

## 6. Rules for adding to this system

1. **Tokens or nothing.** No hex value in a component.
2. **Logical properties only.** Two gates enforce it: an ESLint rule and
   `npm run check:direction`.
3. **Every new surface and ink pairing goes into the contrast matrix** in
   `scripts/build-tokens.mjs` before it is used.
4. **Every interactive component ships its states**: hover, focus-visible,
   active, disabled, loading, empty, error. The styleguide must show them.
5. **Colour never carries meaning alone.** Pair it with an icon, a word, or both.
6. **Motion under 300ms, `transform` and `opacity` only**, and the blanket
   reduced-motion override in `globals.css` must reach it.
7. **Eyebrow budget: one per three sections.** Count before shipping a page.
8. **No new dash characters.** `npm run check:copy` fails the build.
